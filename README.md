## 🧠 What is this?

`KaliLinux_hacking_simulation` is a **browser-based hacking simulator** that mimics the interface and behavior of real penetration testing tools like **Nmap**, **Metasploit**, **Wireshark**, and **Hydra**—but everything is **fake, safe, and gamified**.

This is an immersive terminal-style experience built for:
- Cybersecurity awareness & training
- Students and ethical hackers
- Gamified red-team learning
- YouTube/twitch content creators

---

## 🌐 Features

- ✅ Fake Nmap Port Scanner (animated)
- ✅ Simulated Metasploit Exploit Terminal
- ✅ Virtual Linux Bash Terminal (`ls`, `cd`, `cat`, etc.)
- ✅ Password Brute Force Simulation
- ✅ WiFi Cracking (visual-only handshake simulation)
- ✅ Fake Phishing Scenario Builder
- ✅ Fictional Dark Web Dashboard
- ✅ Firewall Bypass Game
- ✅ Mission-based Challenges & Achievements
- ✅ Leaderboards & User Progress
- ✅ Sound FX, Typing Animations, and Terminal UI
- ✅ Absen Device Compatible
- ✅ Fully responsive across devices
